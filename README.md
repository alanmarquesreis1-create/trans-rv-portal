# Trans RV Portal

Portal web inicial para classificação de bases de transporte.

## Uso
Abra `index.html` ou publique este repositório no GitHub Pages. O processamento XLSX/XLS/CSV ocorre no navegador usando SheetJS.

## Escopo atual
- Importação de múltiplos arquivos
- Leitura de XLSX/XLS/CSV
- Classificação inicial Amazon, Mercado Livre e Shopee
- Visualizações de classificação, TMS e tratativas
- Regras iniciais de operação

Esta é a base inicial do portal; regras completas de frete, persistência, usuários, auditoria e integrações TMS ainda precisam ser incorporadas.
